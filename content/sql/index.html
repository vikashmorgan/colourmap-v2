Query order

You write it

SELECT·FROM·WHERE·GROUP BY·HAVING·ORDER BY·LIMIT

SQL runs it

FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT

So WHERE cannot use COUNT or SUM (use HAVING), and a name made with AS in SELECT is not ready in WHERE.

## Purpose

A study page for the Git course (MSE-DIM01-3, Marco Molè), "similar to the coding app but more sober: less over-information, explaining the key concepts and the key terms I need" to explain to the teacher what was done.

## What it holds

- **What you built:** the five steps of `dim013-project` (skeleton, on GitHub, branch & merge, layout, reproducible).
- **The oral defence:** the seven points of the definition of done, each with what to show and a sentence to say; the fresh clone done live.
- **Key concepts:** why version control, the repository and `.git`, the three areas, Conventional Commits, branches and merging (fast-forward, merge commit, conflict), remotes, pull requests and review, secrets and `.gitignore`, venv and `requirements.txt`.
- **Key terms**, **commands by step**, and **check yourself** questions (answers hidden until opened).

Sources: "The Project, Step by Step" (37-slide version) and "Session 2 · Version Control & Git Fundamentals", kept in ADMIN · classes - ALBERTS · GIT.
